# Навчальний репозиторій

## Про репозиторій

Цей репозиторій створений для виконання та збереження лабораторних і практичних робіт під час навчання в IT-коледжі.

У репозиторії будуть публікуватися результати виконаних робіт, навчальні матеріали, приклади коду та інші матеріали, пов'язані з навчанням.

- **Ім'я:** Юра
- **Навчальний заклад:** [Фаховий коледж інформаційних технологій Національного університету Львівська політехніка]
- **Група:** [КН-230]

## Робота з репозиторієм

Для роботи з репозиторієм використовую **GitHub**, **Git** та **Visual Studio Code**.

Основний порядок роботи:

1. Клонувати репозиторій з GitHub.
2. Внести зміни до файлів.
3. Зберегти зміни.
4. Відкрити вкладку `Source Control`.
5. Додати змінені файли до `Staged Changes`.
6. Створити `Commit`.
7. Натиснути `Sync Changes`, щоб завантажити зміни на GitHub.

## Майбутні роботи

1. Робота з GitHub та Git.
2. Робота з Markdown.
3. Основи програмування.
4. Робота з файлами.
5. Виконання лабораторних робіт.
